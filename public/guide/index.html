How it works

One shared rhythm from setup to progress.

The workflow stays simple for families while preserving clear roles and privacy boundaries.

1

Parent creates the circle

The parent sets up the child’s private care space, measurable goals, interventions, and recurring daily-care items.

2

Caregiver joins safely

A caregiver uses the invitation email, verifies the matching address, and accepts only the access the parent granted.

3

Everyone stays coordinated

Members complete care, record structured outcomes, exchange handoffs, and receive privacy-safe activity notifications.

Role boundaries

The right people see the right things.

Parents retain control. Caregivers can collaborate fully in the day-to-day workflow without changing the parent-managed care plan.

Parent

Full access
  • Create the private care circle
  • Manage goals and interventions
  • Set recurring daily-care templates
  • Invite and manage caregivers
  • Review all progress, updates, and activity

Caregiver

Daily care
  • View assigned daily care
  • Complete items with clear attribution
  • Follow shared interventions
  • Record structured progress outcomes
  • Post handoffs, replies, and community support

Daily care

Care tasks that persist and stay accountable.

Parents create recurring items; caregivers complete them. Every action records who helped and when.

  • Daily and weekday schedules
  • Complete and undo support
  • Real-time parent and caregiver sync

Shared progress

Checklist completion and goal outcomes stay distinct.

CareCircle separates “what was done” from “how independently the goal was achieved,” making progress more meaningful.

  • Structured outcomes
  • Weekly targets and observations
  • History with author and time

Trusted access

Caregivers join the existing circle by invitation.

The verified invited email is matched to the correct care circle. A caregiver does not create a second parent workspace.

  • Seven-day invitation window
  • Email verification before access
  • Read-only parent-managed care plan

Privacy-safe coordination

Shared updates without losing context in group texts.

Requests, replies, activity history, and optional web push help the circle respond quickly while keeping lock-screen text generic.

  • Updates and open requests
  • Shared activity timeline
  • Optional private push notifications
